# 🎓 AI Exam Proctor

🚧 **Project Status:** Under Development

An AI-powered online exam proctoring system that monitors students during exams using Computer Vision and Deep Learning techniques.

## 🚀 Planned Features

- ✅ Face Detection
- ✅ Face Recognition
- ✅ Eye Tracking
- ✅ Head Pose Estimation
- ✅ Mobile Phone Detection (YOLO)
- ✅ Multiple Person Detection
- ✅ Tab Switching Detection
- ✅ Suspicious Activity Alerts
- ✅ Exam Report Generation

## 🛠️ Tech Stack

- Python
- OpenCV
- YOLOv8
- MediaPipe
- Deep Learning
- Streamlit
- NumPy
- Pandas
